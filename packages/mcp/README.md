# @authoryx/mcp

The Authoryx MCP server, over stdio: `npx -y @authoryx/mcp`. It offers the agent seven tools to
list circles and secrets, ask, follow and close requests, and run programs with approved secrets.
None returns a value. Sign in first with `authoryx login`, or set the `AUTHORYX_*` variables. See
the [repository README](https://github.com/AutumLabs/Authoryx#readme) for each host's setup.
