# @authoryx/core

The shared core of the Authoryx agent tools: the tool registry with each tool's tier and
capability, the verbs, `run` with output redaction, and sign-in through the OS keychain or the
environment. The [`authoryx`](https://www.npmjs.com/package/authoryx) command-line tool and
[`@authoryx/mcp`](https://www.npmjs.com/package/@authoryx/mcp) are thin surfaces over it. See the
[repository README](https://github.com/AutumLabs/Authoryx#readme).
