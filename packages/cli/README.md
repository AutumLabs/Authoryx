# authoryx

The Authoryx command-line tool for agents and the scripts they run: sign in, list circles and
secrets, ask with a reason, wait for the owner's answer, and run a program with the approved
secrets in its environment. Also installs the Claude Code guard hook (`authoryx hooks install`).

Run `authoryx --help` for every command. See the
[repository README](https://github.com/AutumLabs/Authoryx#readme).
