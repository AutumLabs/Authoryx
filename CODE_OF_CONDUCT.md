# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent to people. Assume good faith, argue about the work rather
than the person, and accept that a technical disagreement resolved against you
is not a slight.

Report unacceptable behaviour to **conduct@authoryx.com**. Reports are handled
by AutumLabs and kept confidential.
